Все контейнеры, что необходимо запустить:

1) Контейнер бэкенда nobugsme/nbank:with_validation_fix // 4111 -> 4111

2) Контейнер фронтенда nobugsme/nbank-ui:latest // 80

3) Контейнер Nginx nginx:latest (нужно чтобы переотправлялись все запросы на nginx) //nginx 80 -> 80

3) Контейнер Selenoid aerokube/selenoid:latest // 4444 -> 4444

4) Контейнер Selenoid UI aerokube/selenoid-ui:latest // 6567 -> 8080

Шаги по внедрению Docker Compose:

1) Создать docker-compose.yaml
2) Описать каждый из докер контейнеров
(образ откуда собираем, порт чтобы открыть между каждым контейнером, последовательность, общая докер сеть)
3) Скрипт по поднятию всех докер контейнеров с помощью docker compose
